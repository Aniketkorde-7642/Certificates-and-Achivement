## Repository structure

- `Achievement` — (If present) any textual summary or list of achievements.
- `README.md` — This file.

## How to view
1. Browse the `Certificates/` directory on GitHub to view individual files.
2. Click a PDF or image file to preview it in the browser.
3. To download, right-click the file and choose "Download" or use the raw link.
